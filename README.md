# Segway Dynamic Modeling and Control

MATLAB project for modeling the dynamic behavior of a Segway (two-wheeled self-balancing vehicle).

---

## Project Overview

This project involves mathematical modeling and control system design for a Segway in 2D (forward-backward movement). The main goal is to analyze the system's stability and dynamic response.

---

## Completed Work

### 1. System Linearization
- Derived the nonlinear mathematical model of the Segway.
- Performed **linearization** around the upright equilibrium point.
- Obtained the state-space representation of the linearized system.

### 2. Transfer Function and Feedback Control
- Derived the **transfer function** of the system.
- Designed a closed-loop system with feedback.
- Analyzed the system's behavior in the forward-backward direction (longitudinal movement).
- Simulated step response and analyzed stability in the time domain.
